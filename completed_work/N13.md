# N13 — API module tidy-up from the API-group gap review

## Origin

A main-agent gap review of the API group (`e3ad2a6..b4a59da`, 2026-10-11) found one Low gap and four Nits; that review did not use the adversarial-review skill. The user asked for all of them to be fixed. The other gap went to [NB35](NB35.md). N13 was given an ID, fixed and closed in the same commit.

## Boundary

The following changes were made without changing behavior:

1. **Endpoint bodies.** The four synchronous endpoint bodies added by [NB15](NB15.md) had public names. NB15's record called them endpoint internals "like the D42 helpers", but no user decision covered them. They now carry a leading underscore, so their internal status needs no [D18](../DESIGN.md#d18) classification, and NB15's record carries a dated correction.
2. **Public names kept.** `prepare_tasks`, `PreparedTasks`, `resolve_filesystem_tasks`, `group_files_by_stem` and `redundant_media_paths` stay public. [D42](../DESIGN.md#d42) names their module and the N1 helpers.
3. **Test name.** The misnamed `test_add_tasks_routes_youtube_and_whisper_work`, which uses the Azure transcriber, was renamed.
4. **Test order.** API tests were reordered to source order. The re-export identity and sanitized-500 tests now come first. The cross-endpoint concurrency tests stay after the last endpoint's tests, with a comment explaining why.
5. **Comment placement.** A misplaced comment above `router` became a module docstring.
6. **Links.** Mentions of NB29 and NB15 in `N1.md` and `history.md` now link to their completion records.

Compatibility surface: the four renamed functions first appeared in `b4a59da` that same day and had no other callers. The endpoint coroutines, the HTTP contracts and every name that was public before this group are unchanged.
