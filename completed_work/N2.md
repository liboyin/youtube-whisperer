# N2 — Empty media directories produce a fictitious filename

## Origin

A 2026-09 assessment ([historical assessments](history.md#evidence-provenance)) classified N2 as a Nit, Low severity, Validated by an owned empty-directory shell reproduction. [ls_mp4_without_srt.sh](../ls_mp4_without_srt.sh) iterated an unmatched glob literally, so a directory with no MP4 files printed `<directory>/*.mp4` and exited 0. Acceptance required that an empty directory produce no paths, and that missing or present SRT files and file names containing spaces still be handled correctly.

N2 was executed with [NB21](NB21.md) and [NB20](NB20.md) as a shell-helper group. None of the repository's shell tools had tests before this group. Each task was committed and reviewed separately.

## Boundary

- **Intent:** print only existing `.mp4` files that lack a sibling `.srt`.
- **Direction:** enable bash `nullglob` before the loop, so an unmatched glob produces no iterations.
- **Compatibility surface:** the CLI only. Preserved:
  - the usage message and exit 1 when the argument is missing;
  - the `Error: Directory '<path>' not found.` message and exit 1;
  - the `<directory>/<name>.mp4` output form, glob order, and exit 0 on success.
- **Non-goals:** case-insensitive suffixes, recursion, and directories named `*.mp4`.

## Change

- [ls_mp4_without_srt.sh](../ls_mp4_without_srt.sh) runs `shopt -s nullglob` after the directory check, with a one-line comment.
- [test_ls_mp4_without_srt.py](../tests/tooling/test_ls_mp4_without_srt.py) adds 5 tests. Each runs the script with `bash` in a fresh subprocess, using an explicit minimal environment (`PATH=os.defpath`, `HOME` and `TMPDIR` under `tmp_path`, `LC_ALL=C.UTF-8`) and `cwd=tmp_path`. The tests cover the usage and missing-directory errors, an empty directory, a directory with no MP4 files, and a mixed directory whose name contains a space.

README's description of the script remains accurate and is unchanged.

## Mutation evidence

The implementation agent produced the evidence. Every run used a disposable copy of the candidate, deleted afterwards, with `PYTHONPATH`, `TMPDIR` and `--basetemp` inside that copy and seed `12345`. A hook added only to the copy's conftest confirmed that the test file and `SCRIPT` were inside the copy. It also printed the executed script's sha256 prefix: `54168ac18f3ced47` for the unmutated baseline, which passed all 5 tests, and a distinct prefix for each mutant.

| Mutant | Protected property | Result |
|---|---|---|
| Remove `shopt -s nullglob` | An unmatched glob prints nothing | Killed: 2 failed, literal `*.mp4` path printed |
| Unquote `"$srt_file"` in the existence test | Names with spaces check their own SRT | Killed: 1 failed, `[: too many arguments` |
| Invert the existence test | Only MP4 files lacking an SRT are listed | Killed: 1 failed |
| Unquote the directory in the glob | Directory paths containing spaces work | Killed: 1 failed |
| Print the SRT path instead of the MP4 path | Output takes the form `<directory>/<name>.mp4` | Killed: 1 failed |
| Missing directory exits 0 | Missing-directory failure status | Killed: 1 failed |
| Usage exits 0 | Missing-argument failure status | Killed: 1 failed |

Glob order is asserted but not separately mutated, because bash has no simple order-reversing mutant of a single glob.

## Review

- **Reviewer:** a new Codex session, `01a13036-1a6e-70c1-b5f0-d8ebb3577c82`, model `gpt-6.1-sol`, reasoning effort `high`, both verified from the dispatch arguments. This was a full first assessment of the frozen candidate.
- **Focused run:** in scratch, the reviewer ran the 5 tests and they passed (seed 12345). Scratch provenance checks covered the script's location and hash.
- **Mutation check:** the reviewer independently re-ran the `nullglob` removal, which was killed with 2 failures. It verified the six other supplied mutants' identities and outcomes without replaying them.
- **Probes:** additional probes found the expected behavior for:
  - relative paths containing spaces or glob metacharacters;
  - a directory where every MP4 has an SRT;
  - an existing file literally named `*.mp4`;
  - uppercase, hidden and nested exclusions;
  - a non-directory argument.
- **Verdict:** no Blocking findings, Non-blocking findings or Nits. The main agent's post-review snapshot matched the frozen pre-review snapshot exactly.

## Limitations and cleanup

Shell scripts are not measured by coverage.py; the subprocess tests and the mutation evidence protect them instead. The implementation clone and every mutation and review scratch copy were deleted. Unrelated untracked files were preserved.
