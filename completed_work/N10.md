# N10 — Source ISO conversion uses one transformation

## Origin

TODO recorded a validated Nit (a proposed simplification, not a runtime defect). `LanguageCode.get_source_as_ISO` handled BCP-47 and ISO 639-1 sources in separate branches, although both yield `source.split('-', 1)[0]` for every registered code. NB32 had already removed the target-conversion API under [D23](../DESIGN.md#d23)/[D24](../DESIGN.md#d24).

## Boundary

Remove the redundant membership branch from source ISO conversion. Keep ISO output identical for every registered code. Retain whitelist validation, the strict constructor versus normalizing `from_str` difference, and the BCP-only `UnableToConvertLanguageCode` error from `get_source_as_BCP`. Other conversion methods, the whitelist and parsing were out of scope. Compatibility surface: the public method `get_source_as_ISO` ([D18](../DESIGN.md#d18)) keeps its output for every registered code. Its callers in the Whisper transcriber and transcript downloader are unaffected. The task was delivered with [NB17](NB17.md) by one implementation agent, but committed and reviewed separately.

## Revalidation

At `9d03f03`, `get_source_as_ISO()` equalled `source.split('-', 1)[0]` for `en`, `en-us`, `zh` and `zh-cn`.

## Change

[lang_code_adaptor.py](../youtube_whisperer/adaptors/lang_code_adaptor.py) now returns `self.source.split('-', 1)[0]` from `get_source_as_ISO`, with a Google-style docstring explaining why one split covers both forms. In [test_lang_code_adaptor.py](../tests/adaptors/test_lang_code_adaptor.py), `test_get_source_as_iso_converts_every_registered_code` replaces the two-case test. It asserts that the registered set is exactly the four expected codes, then compares each conversion with an explicit expected value. Both previous cases are retained.

## Mutation evidence

This simplification protects no high-impact invariant, but the implementation subagent produced one probe in the isolated, provenance-checked setup described in [NB17](NB17.md#mutation-evidence), with seed `20261011`. The mutant made `get_source_as_ISO` return `self.source`. It was killed: 2 tests failed (`test_get_source_as_iso_converts_every_registered_code` and `test_get_source_as_bcp_and_iso`), for example with `{'en-us': 'en-us'} != {'en-us': 'en'}`. The reviewer independently replayed it on the exact N10 target: 55 passed unmutated, 2 failed under the mutant, and imports were verified from scratch.

## Limitations and cleanup

Behavior is verified only for the four registered codes; for a future registered code without a subtag, the single split still returns the code unchanged. Scratch trees were deleted, and unrelated untracked files were preserved.
