# NB39 — Callers still hand-roll their publication stages

## Origin

pathlib-extensions `fff2bf6` added `StagedFile`, a context manager that creates a private hidden directory beside the resolved destination. The body writes the file there; it is published with `publish_staged_file` after a clean exit, and the directory is removed on every exit.

The user decided ([D48](../DESIGN.md#d48), 2026-10-22) to move video, SRT and WAV publication onto it, superseding the part of [D46](../DESIGN.md#d46) that deferred a context manager. [NB38](NB38.md) (`60e7896`) had already pinned `fff2bf6`.

## Boundary

- **Intent:** each caller writes its output inside a `StagedFile` instead of creating, tracking and removing its own stage. The [completion contract](../DESIGN.md#srt-as-the-output-format) and [D22](../DESIGN.md#d22) are unchanged.
- **Video:**
  - Preflight, then `prepare_output_file`.
  - The expanding-parent check runs on the resolved parent, still before any stage exists.
  - yt-dlp writes a fixed `video.mp4` inside the stage directory, so titles never enter its output template ([NB8](NB8.md)).
  - The regular-file check keeps its `FileNotFoundError`, and the file is renamed to the staged name.
- **SRT:** text is written to an exclusively created file inside the `StagedFile` and closed before publication.
- **WAV:**
  - The caller's destination *name* is created exclusively inside the stage directory, and ffmpeg converts there.
  - ffmpeg therefore still infers the container from the caller's suffix when a symlinked destination's target has another suffix.
  - The result is renamed to the staged name.
- **Preserved:**
  - preflight before work;
  - publication only after a successful body (and, for video, after the downloader context exits);
  - `NEVER` keeps competitors, and `ALWAYS` replaces atomically, follows symlinks and keeps mode bits;
  - failures keep previous output;
  - the stage is removed on every exit, and an abrupt exit leaves at most a hidden directory, never a partial final file;
  - new-file permissions are unchanged;
  - an interrupted ffmpeg child is killed, drained and reaped and its pipes are closed before the stage is removed.
- **Non-goals:**
  - forwarder removal ([NB40](NB40.md));
  - stale-stage scavenging;
  - power-loss durability.

## Change

- **Callers:** [video_downloader.py](../youtube_whisperer/downloaders/video_downloader.py), [srt_deduplicator.py](../youtube_whisperer/adaptors/srt_deduplicator.py) and [waveform_loader.py](../youtube_whisperer/transcriber/waveform_loader.py) use `StagedFile`. The `uuid4`, `tempfile`, `shutil` and per-caller ownership code is gone.
- **Stage names:** `.video-*/`, `.srt-*.tmp` and `.wav-*<suffix>` are replaced by `.staging-<random>/`.
- **Tests:**
  - **Obsolete tests replaced:** the SRT and WAV `uuid4` stage-collision tests no longer apply, because each publication gets its own private directory and this project no longer deletes stage files itself. They are replaced by tests that an unrelated `.staging-unrelated` stage beside the output survives both success and failure.
  - **Adapted:** the process-exit test now finds the partial file inside the stage directory. Stage globs and parent assertions, and the video expanding-parent spy (now on `StagedFile`), are updated.
  - **Interruption tests:** the two WAV interruption tests now observe the actual cleanup at `shutil.rmtree` and assert that the observer ran (see [Review](#review)).
- **DESIGN:** the video, WAV, SRT and completion-contract paragraphs describe `StagedFile` and `.staging-<random>` directories.

## Limitations and cleanup

- **Remote install not exercised:** pip installation from the remote was not exercised.
- **Reinstall required:** environments still holding an older library need dependencies reinstalled.
- **Library-owned behavior:** stage creation and cleanup are now library behavior. This project's tests observe them only through its callers, with the library's own tests covering the rest.
- **Cleanup:** scratch copies were removed; working evidence lived in temporary session storage, and its essentials are preserved here.
