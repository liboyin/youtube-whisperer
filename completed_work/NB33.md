## Change

[postCreateCommand.sh](../.devcontainer/postCreateCommand.sh) installs Codex with `curl -fsSL https://chatgpt.com/codex/install.sh | CODEX_NON_INTERACTIVE=1 sh`, then exposes `~/.local/bin` in the current provisioning shell and runs `codex --version`. Installation precedes that temporary PATH export so it does not suppress the installer's persistent shell PATH setup. The two plugin commands and the 236-line resolver were removed. [README](../README.md#dev-container-recommended) describes installation and sign-in; [D30](../DESIGN.md#d30) describes the current setup without a date; TODO's active NB33 entry was removed.

## Removed-layer ownership

The resolver selected usable extension builds by modification time with fallback, preserved foreign destinations, atomically replaced managed links, tolerated stale links, installed an idempotent zsh repair hook, and reported failures without failing provisioning. Standalone Codex does not need the companion Node runtime or extension discovery. Command installation, updates, shell PATH setup and installation diagnostics now belong to the native installer. The creation hook's existing `set -euo pipefail` propagates install failures, and its version check verifies command execution. Existing installations and previously appended repair hooks were not migrated or removed.
