## Boundary

  - The skill calls the shared `../agent-workflow-common/tools/snapshot.py` and `dispatch.py`.
  - Every scratch run goes through a port of collector's `mutate.py`, and `worktree_gates.py` can freeze a candidate in a worktree.
  - `agent-workflow.json` configures the shared tools, and `check-coverage.sh` matches collector's.
- **Dependencies:** youtube-collector at `5a95c4d`, whose tools this change ports. The unpinned `agent-workflow-common` checkout ([D56](../DESIGN.md#d56)) at `b14b8a9`, which resolves links to `<a id>` anchors.
- **Compatibility surface:**
  - `./check-coverage.sh` now refuses, before pytest runs, a `python3` that does not match `.python-version` (`3.12`) or a `youtube_whisperer` that resolves outside the working directory. It must run from the repository root, as the README already showed.
  - The reviewer model and effort change, and Claude Code dispatches through `dispatch.py` instead of a hand-written `codex exec` command.
  - No application, API, CLI, Compose or image behavior changes.
- **Non-goals:**
  - AGENTS, STYLE, `tests/README.md` and the wholesale replacement of the skills, which are the governance change.
  - The task layout, which is the last change.
  - Collector's network guard (its C58), its explicit Ruff rule selection, and its `filterwarnings = ["error"]`, `--strict-markers` and `xfail_strict` pytest settings. Each changes test or lint behavior repository-wide and needs its own decision.
  - Pinning or changing `agent-workflow-common` beyond the anchor fix.
- **Validation:** gates on a `df77685` baseline and on the candidate, also run by `worktree_gates.py` in a frozen worktree. Mutation evidence for the gate's refusals, the package rename in both tools, `mutate.py`'s verdict, and the removed snapshot coverage. A `mutate.py --tests` smoke run on application tests. Then a review through `dispatch.py`.
- **Done:** gates pass, the review has no Blocking finding, and the change is committed.

## Change

- **`.agents/skills/adversarial-review/references/mutate.py` and `worktree_gates.py`:** collector's scripts at `5a95c4d`, with `youtube_collector` renamed to `youtube_whisperer` and mode 755. Each also passes an explicit `check=False` to the one `subprocess.run` whose status it reads itself. Ruff 0.17.6's default rules here include EXE001 and PLW1510, which collector's explicit rule selection leaves out.
- **Fixes from the review,** to code that collector has too (see [Review](#review)):
  - `mutate.py` checks each copied symlink again in the copy. Before reading a mutant's file, it refuses a path that is absolute, climbs out of the copy, or is or lies below a symlink. It writes the mutant, and later the original, to a new file with the original mode that atomically replaces the path. A symlink or hard link that a test put in place therefore never carries a write out of the copy. It stops the batch if a test replaced a parent with a link. Its candidate digest also covers each file's kind and mode.
  - `worktree_gates.py` records the worktree's `HEAD` and the named paths with their fingerprints in the worktree's own git directory at the freeze. `--compare` and `--remove` refuse a worktree without a readable record, or whose `HEAD`, named files or unnamed paths changed since. They compare every named path. `--remove` also refuses while the worktree's index stages a change.
  - `check-coverage.sh` also requires the resolved package to lie inside the working directory, so a symlinked package cannot pass it.
  - The scratch recipe says to read a kill's failure detail, because a `TypeError` that the mutated code raises still counts as `KILLED`. The skill says to freeze the candidate in a worktree before scratch runs when tracked files outside the scope are dirty.
- **`references/snapshot.py` and `tests/tooling/test_snapshot.py`:** removed. The shared `tools/snapshot.py` is the removed helper plus a `mode` for symlink entries. Its `tests/test_snapshot.py` keeps all 17 removed test functions with the same assertions. It adds that mode to two of them, and adds one test.
- **`check-coverage.sh` and `tests/tooling/test_check_coverage.py`:** collector's versions with the package renamed.
- **`tests/tooling/test_review_tools.py`:** collector's tests of both tools with the fixture package renamed. It loads the two scripts by file path as `mutate` and `worktree_gates`, as collector's does. This keeps the file in step with collector's, where a file holds the tests of two scripts. The governance change adopts collector's test conventions.
- **`agent-workflow.json`:** style checks on changed lines only for `DESIGN.md` and `completed_work/`, and the reviewer's safety rule for this project.
- **Skills:** the review skill's Reviewer Session uses `dispatch.py` and `gpt-6.2-sol` with high effort. Its step 1 uses the shared snapshot and names `worktree_gates.py`. Step 2 requires `mutate.py` for every scratch run, and step 3 runs focused tests with `mutate.py --tests`. `scratch-testing.md` is collector's recipe for `mutate.py`, with collector's link to its network conventions replaced by the reserved destinations they name. The group workflow names the new reviewer model.
- **Docs:** README's Testing section (the gate's refusals, the review tools, the shared tools and `check_docs.py`). DESIGN gains D58, and D41 is marked as superseded in part.

## Review

- **Procedure:** the review skill as this change leaves it, dispatched with the shared `dispatch.py`. The working record was machine-local and outside the repository. This record holds the evidence that other machines need.
- **Reviewer:** Codex session `01a203af-0d87-7480-9605-888848fe1162`, dispatched with `gpt-6.2-sol` and high effort, which `dispatch.py` passes to the CLI.
- **First assessment:** the dispatch exited 0, and the integrity snapshot after it matched the one before it. The reviewer reproduced W1–W7 and S1–S4 and ran seven boundary probes. Its verdict was 4 Blocking findings.
- **Findings and dispositions.** Each Blocking finding was validated by reading the code, and each holds in collector's tools too:
  1. **Blocking**, writes can escape the copy. A relative link with surplus `..` components passed the copy check and led from the copy back to the original. An absolute mutant path changed a file outside the copy. Validated and fixed (F1–F3).
  2. **Blocking**, `--compare` can accept a changed frozen worktree, because it compared only the paths that differed from `HEAD`. Validated and fixed with the freeze record (F4, F5, F7).
  3. **Blocking**, `--remove` can discard a change staged only in the worktree. Validated and fixed (F6).
  4. **Blocking**, the gate accepts a symlinked package outside the working directory. Validated and fixed (F8).
  5. **Non-blocking**, a `TypeError` raised by broken mutated code counts as a behavioral kill. Validated. Deferred with a mitigation: the recipe now says to read each kill's failure detail. A `TypeError` can also be a genuine behavioral failure, so reclassifying it in the tool would hide real kills. Revisit when the tool can tell where an exception was raised, or when an invalid kill reaches evidence.
  6. **Non-blocking**, the candidate digest omits mode and kind. Validated and fixed (F9).
  7. **Non-blocking**, scratch runs copy unrelated tracked edits. Validated. Deferred with a mitigation: the skill now says to freeze the candidate in a worktree first when tracked files outside the scope are dirty. Revisit when the governance change replaces the skill.
- **Follow-up assessment:** the dispatch with `--resume` exited 0, and the integrity snapshot after it matched the one before it. The reviewer reproduced all 20 mutation kills and found that the fixes resolve findings 1–4 and 6. It accepted the deferrals of findings 5 and 7. Its verdict was 2 Blocking findings and a Nit:
  1. **Blocking**, the restore after a mutant can follow a link that a test put in place of the file. Validated and fixed (F10, F11).
  2. **Blocking**, the freeze record misses a commit in the worktree and changes to unnamed paths. A forced removal could then discard an unmerged commit. Validated and fixed (F12, F13). Because the record's format changed, an unreadable record is now also a clean refusal (F14).
  3. **Nit**, the W3 count was stale. Validated and fixed.
- **Second follow-up:** the dispatch exited 0, and the integrity snapshot after it matched the one before it. The reviewer reproduced F1–F13 and the earlier probes, and kept the deferrals of findings 5 and 7. Its verdict was 1 Blocking finding and 1 Non-blocking:
  1. **Blocking**, both the mutant's write and the restore wrote through the existing inode, so a hard link that a test made carried them out of the copy. A file replaced by a symlink also lost its mode, so the next mutant started from a different state. Validated and fixed (F15–F17, F19).
  2. **Non-blocking**, a record with the right `head` and `"files": null` raised a `TypeError`. Validated and fixed (F18).
- **Third follow-up:** the dispatch exited 0, and the integrity snapshot after it matched the one before it. The reviewer reproduced F1–F19 and all eight earlier probes, and kept the deferrals of findings 5 and 7. Its verdict was no Blocking findings, with one Nit: the F14 count was stale. Validated and fixed.
