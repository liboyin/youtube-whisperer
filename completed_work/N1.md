# N1 — Asset cleanup reconstructs the wrong case-sensitive paths

## Origin

TODO recorded a validated Nit (owned-file reproduction): `map_path_to_suffixes` stored lowercased suffixes and `redundant_media_paths` rebuilt `f"{stem}{suffix}"`. On Linux, `video.mp4` + `video.srt` + `video.WAV` selected the nonexistent `video.wav`, so `DELETE /assets` left the redundant WAV. N1 was executed as candidate 1 of the API group with [NB29](NB29.md) and [NB15](NB15.md), each committed and reviewed separately.

## Boundary

Remove the actual on-disk MKV/WAV/MP3 files of a stem that has both an MP4 and an SRT, matching suffixes case-insensitively and never reconstructing paths. Stems stay compared exactly (`Video.mp4` + `video.srt` remain unrelated), the transient suffix set is unchanged, and the scan keeps its `rglob` + `is_file` semantics, including file symlinks. The response lists the removed paths as spelled on disk, sorted. Compatibility surface: the `DELETE /assets` HTTP contract changes only by the corrected selection; `GET /assets` is unchanged; the `clean_assets(dir_path)` coroutine is preserved. The user decided ([D42](../DESIGN.md#d42)) that `map_path_to_suffixes` and `redundant_media_paths` are endpoint internals that [D18](../DESIGN.md#d18) does not require preserving, so they were replaced in place. Concurrency was left to NB15.

During integration the main agent amended the boundary. The removed pre-unlink `is_file()` guard had one unique behavior: a selected file that vanished before deletion was skipped instead of failing the request. N1 now owns that behavior, treating `FileNotFoundError` from the unlink as "already gone" (not reported) while other `OSError`s propagate. This item moved here from the NB15 boundary.

## Revalidation

At `e3ad2a6`, `api/app.py` lines 205–261 matched the TODO description: lowercased suffix sets, reconstructed paths and an `is_file()` guard that silently skipped the nonexistent lowercase paths.

## Change

In [app.py](../youtube_whisperer/api/app.py), `group_files_by_stem(dir_path)` replaces `map_path_to_suffixes`, grouping actual file paths by their exact path without suffix. `redundant_media_paths(files_by_stem)` remains pure: a stem is complete when its lowercased suffixes include `.mp4` and `.srt`, and every file whose lowercased suffix is `.mkv`, `.wav` or `.mp3` is returned exactly as supplied, so case variants such as `video.wav` and `video.WAV` are both selected. The suffix sets are module constants. `clean_assets` unlinks the selected paths, skips any that raise `FileNotFoundError`, and returns the paths it removed, sorted. DESIGN's `DELETE /assets` contract row and the new D42 decision row were updated.

[test_app.py](../tests/api/test_app.py) replaces the mapper/selector tests with tests over actual case variants. A `touch_distinct` helper asserts that the filesystem keeps case variants distinct before each such test relies on it. The endpoint test now uses real owned files without patching the mapper. New tests cover file symlinks and broken symlinks during grouping, a vanished selected file, and propagation of another deletion error (`IsADirectoryError`).

## Limitations and cleanup

A selected path that turns into a non-file (for example, a directory) before deletion now propagates as a 500, where the old `is_file()` guard skipped it; only a missing file is treated as already gone. The tests rely on the case-sensitive Linux filesystem and assert that precondition. Scratch trees were deleted, and unrelated untracked files were preserved.
