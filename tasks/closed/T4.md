## Implementation

- **Moves:** the 38 records from `completed_work/` to `tasks/closed/`, and `completed_work/history.md` to `project-reviews.md`, with `git mv`. `completed_work/` no longer exists.
- **Links:** a script resolved each relative link of every Markdown file against the file's location before the move. It mapped the old target to the new one, and wrote the link relative to the file's new location. Links into the old TODO maintenance section now point to `tasks/README.md#maintaining-tasks`. The script's first run missed renames that `git status` shows as `RM`. It damaged 22 links of `project-reviews.md`, which was restored from `HEAD` before a corrected second run.
- **Outcome lines:** each record gains its TODO summary under its title, with the links rewritten for its location. Semicolons, slashes and long sentences in 22 of them were split or reworded to meet STYLE, without changing their meaning.
- **Open tasks:** `tasks/open/NB2.md` and `tasks/open/NB31.md` hold their TODO entries, rewritten in STYLE with every fact kept. NB2 takes the investigation gate from TODO's "Design dependencies" section. Each gains a revalidation note of 2026-11-23: Ruff's wider default rules for NB2, and D54 superseding D10 for NB31.
- **`tasks/TODO.md`:** the recommended order takes TODO's readiness notes. The shared constraints take its evidence provenance, its integration checks and its rule for live services. Its workflow pointer is dropped, because AGENTS owns it.
- **`tasks/README.md`:** collector's task rules. The compatibility surface names the public Python APIs of D18. New tasks take the next `T` ID under D57. The closing checklist names this project's DESIGN sections, and the skeleton drops collector's host-check task.
- **Governance:** AGENTS, STYLE and the skills return to collector's wording for the task directory, `project-reviews.md`, the task rules and the boundary of a task. STYLE lists `project-reviews.md`, README.md and TRANSCRIPTION_REDESIGN.md as documents that are not rewritten as a whole.
- **`project-reviews.md`:** collector's header, then the text of `history.md` unchanged apart from its links. Its reference to the old closure index now links NB33's record.
- **`agent-workflow.json`:** the task ID pattern `(?:T|NB|N|B)\d+`, the title separators ` —` and `:`, and changed-line style checks for DESIGN, README, TRANSCRIPTION_REDESIGN, `project-reviews.md` and `tasks/closed/`.
- **DESIGN:** D60, D37 marked as superseded, and `tasks/` in the structure listing. README's links name `tasks/`.
