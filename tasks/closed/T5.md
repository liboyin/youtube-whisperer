## Implementation

- **`postCreateCommand.sh`:** the comment on the PATH export says that no later step needs it now. The hook is now byte-identical to collector's. The handover expected one remaining difference in the lock message's comment, but collector's comment is already the same.
- **`mutate.py`:**
  - `_target_state` records each target's text and mode before the baseline, and refuses a target that is not a regular file.
  - Before each mutant, the batch stops if a test changed the target's text or mode. Otherwise a mutant whose old text a test removed would do nothing, and the test's own change could count as a kill.
  - The target is read, written and restored with `newline=''`, so a mutant keeps CRLF line endings.
  - The module docstring, now a raw string, says that the snippets match line endings literally.
- **`worktree_gates.py`:** `_relative` stores and matches paths as Git spells them, and refuses empty, absolute and climbing paths. `--changed` names get the same normalization. `--compare` and `--remove` refuse a freeze record whose paths `_canonical` rejects.
- **Tests:** `tests/tooling/test_review_tools.py` gains collector's T64 tests. These cover the changed target, CRLF files, a directory target, the parametrized path refusals, `--changed` spellings, non-canonical freeze records and the stored Git spelling. The hard-link test now uses a sentinel that equals the candidate in its baseline case, and a leak marker.
- **Review skill:** the main agent freezes a candidate before dispatch. The reviewer never freezes one, because the freeze registers a worktree in the repository's Git metadata.

After the port, the normalized `mutate.py`, `worktree_gates.py` and `test_review_tools.py` are identical to collector's, and both scripts keep mode 755. The skill differs only in its review focus areas.
