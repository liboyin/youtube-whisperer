# Grouped Task Execution

This repository-local skill records the user's recommended workflow. [AGENTS.md](../../../AGENTS.md) owns working standards, [TODO.md](../../../TODO.md) owns task boundaries and maintenance, and the [adversarial review skill](../adversarial-review/SKILL.md) owns review mechanics. Follow those documents without duplicating their procedures. Explicit user instructions take precedence over this recommendation.

1. **Select and bound the group.** Find a small, high-value group of closely coupled TODO tasks sharing a behavior, invariant, or dependency. Revalidate them against current code and expand each task into its own execution boundary under TODO's rules. Keep the accepted boundaries available for the final review even after completed entries are removed from TODO. Grouping tasks does not expand their authorized scope or settle unresolved material decisions.
2. **Order and delegate.** Implement foundations before dependent behavior. Assign each task to its own GPT-6 Sol subagent (`model: "gpt-6-sol"`), using `fork_turns: "none"` with an explicit assignment so the model override is supported. Supply the task boundary, dependencies, repository path, relevant documentation, and unrelated work to preserve. Execute dependent tasks sequentially, making validated prerequisite changes available before dispatching the next task. Parallelize only independent work with compatible edit and validation boundaries. The main agent owns integration and verification.
3. **Complete each task.** Integrate its implementation and documentation, satisfy AGENTS' validation and per-change review requirements, and create a self-contained commit unless the user requested uncommitted work. Maintain TODO according to its own rules. Delegate bounded implementation work while keeping final validation, review dispatch, finding disposition, and commit ownership with the main agent.
4. **Review the integrated group.** After all tasks are integrated, use a fresh GPT-6 Astra subagent (`model: "gpt-6-astra"`, `fork_turns: "none"`, `reasoning_effort: "high"`) for a full gap review. Target the complete group from its pre-implementation revision through the final candidate, including any in-scope uncommitted changes. Cover the group's accepted boundaries, acceptance criteria, retained behavior, affected call paths, tests, and documentation. Follow the adversarial review skill's complete procedure, overriding only its reviewer model for this final group review with the user's recommended GPT-6 Astra. Required per-change reviews remain in force; the final review may also satisfy the last task's review when it covers that exact candidate before commit. If the requested model or dispatch is unavailable, follow the review skill's handling of unavailable dispatch rather than silently substituting a model.
5. **Close the group.** Investigate and disposition all findings under AGENTS and the review skill. After fixes, repeat required gates and obtain a fresh review of the updated integrated group. Report completion only when each task's done criteria and every required finding disposition are satisfied, identifying the changes, validation, final review verdict, and material limitations.
